# IP and asset provenance

## Current evidence

The pinned Remix and Remux repositories each contain an MIT license with the notice “Copyright (c) 2023 veprogames.” The Remix HTML describes the game as inspired by Idle Mine by Crovie and credits Crovie for the game concept. It also credits AD Notations for number formats.

This establishes the license notice present in those repositories; it does not establish rights that an upstream author may not have held. Do not make legal conclusions from repository metadata alone.

The original Idle Mine source/license was not identified during bootstrap. The attribution history of the old Android port is uncertain. The Remix game JavaScript is not copied into Beyond's product directories. One unmodified Remix mine-object atlas is intentionally included for the Story Canvas adapter; it has a separate provenance record below. The publisher's rights to license inherited original-game art remain unverified.

## Provenance ledger for future derived work

| Field               | Required information                                                |
| ------------------- | ------------------------------------------------------------------- |
| Item                | Source file, asset, font, text, audio, code, name, or brand         |
| Origin              | Canonical source URL, repository, revision, or creator              |
| Relationship        | Copied, adapted, independently reimplemented, or merely referenced  |
| License/permission  | Exact detected license or written permission; unresolved if unknown |
| Notice              | Required copyright and license notices                              |
| Product destination | Tracked path and distribution surfaces                              |
| Decision            | Reviewer, date, and rationale                                       |

## Specific watch items

- Remix code and assets inherit the repository's MIT notice only to the extent its publisher had rights to license them.
- The original Idle Mine relationship and any original-derived art/text require separate provenance review.
- Fonts and third-party notation libraries should be audited individually before redistribution.
- Names, logos, screenshots, and store branding are not automatically cleared by the source-code license.

## Distribution gate

Before public or commercial release, review the provenance ledger and license obligations with the appropriate rights holder or qualified counsel. Keep this as an evidence workflow, not an assertion that publication is legally cleared.

## Mining transition implementation provenance

The pure hit, timer, object-break, reward, and composed action transition in `packages/core/src/remix-mining-transitions.ts` is an independent implementation derived from the pinned Remix paths `Scripts/main.js`, `Scripts/Define/functions.js`, and `Scripts/mineobject.js`. ## UI asset provenance

The Story, Settings, upgrade, and Powers panels use 27 unmodified PNG UI images from the pinned `Images/` tree, including the `story.png` Story-tab icon, the 15 unique Money/Gem/Planet Coin upgrade card icons, the Powers table's `pickaxe.png`, and three Settings social icons from `Images/social/`. Their SHA-256 values were checked against the clean Remix checkout at `0e0f4bf5a9c66e5603cda2ce4bd54213023dae21`; paths and hashes are recorded in [the asset manifest](sources/ui-assets.json) and verified by `pnpm assets:check`. The full Remix MIT notice is adjacent under `apps/web/static/Images/LICENSE.txt`; exact full-text copies also accompany the generated content package and web license directory. As with the atlas, the publisher's rights to inherited original Idle Mine art remain unverified.

The pinned Remix repository also contains the exact Work Sans and Montserrat WOFF2 files used by the source UI. Beyond copies those binaries byte-for-byte and keeps an OFL 1.1 notice next to each. Their Google Fonts metadata records are pinned at `b35c81086186162164947bd39574683073d9b268` for Work Sans and `cc8daf2e7085006b9c112542fc82b58afc13521d` for Montserrat; URLs and local hashes are in the asset manifest. For Montserrat, the official Google Fonts metadata says Copyright 2011 The Montserrat Project Authors, while the bundled OFL notice says Copyright 2024 The Montserrat.Git Project Authors. Both cite SIL OFL 1.1. This source-metadata mismatch is recorded rather than silently reconciled; preserve the supplied notice and obtain a rights-holder clarification before distribution if needed.
