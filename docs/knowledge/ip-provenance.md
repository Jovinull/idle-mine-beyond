# IP and asset provenance

## Current evidence

The pinned Remix and Remux repositories each contain an MIT license with the notice “Copyright (c) 2023 veprogames.” The Remix HTML describes the game as inspired by Idle Mine by Crovie and credits Crovie for the game concept. It also credits AD Notations for number formats.

This establishes the license notice present in those repositories; it does not establish rights that an upstream author may not have held. Do not make legal conclusions from repository metadata alone.

The original Idle Mine source/license was not identified during bootstrap. The attribution history of the old Android port is uncertain. The Remix game JavaScript is not copied into Beyond's product directories. One unmodified Remix mine-object atlas is intentionally included for the Story Canvas adapter; it has a separate provenance record below. The publisher's rights to license inherited original-game art remain unverified.

## Reference material in tests

The initial parity corpus contains normalized runtime outputs for mine objects and default formulas, extracted from the pinned Remix implementation at `0e0f4bf5a9c66e5603cda2ce4bd54213023dae21`. It is derived data, not copied JavaScript or artwork. The fixture identifies the source paths and copyright/license notice; the corresponding full upstream notice is preserved in [idle-mine-remix-MIT.txt](sources/licenses/idle-mine-remix-MIT.txt). The publisher's ability to license any inherited original-game material remains unverified.

The runtime CDN JavaScript response snapshots live only in ignored `.research/`; the tracked manifest records their versions, hashes, and npm license metadata. The snapshots themselves are not bundled assets. `@antimatter-dimensions/notations@1.6.0` is now an explicit product dependency; its upstream MIT license is included in the installed package, and no upstream source or assets were copied into product directories. The short display wrappers were independently implemented from Remix's `Scripts/Define/functions.js` and are golden-tested against the extracted outputs.

## Specific watch items

- Remix code and assets inherit the repository's MIT notice only to the extent its publisher had rights to license them.
- The original Idle Mine relationship and any original-derived art/text require separate provenance review.
- Fonts and third-party notation libraries should be audited individually before redistribution.
- Names, logos, screenshots, and store branding are not automatically cleared by the source-code license.

## Distribution gate

Before public or commercial release, review the provenance ledger and license obligations with the appropriate rights holder or qualified counsel. Keep this as an evidence workflow, not an assertion that publication is legally cleared.

## Mining transition implementation provenance

The pure hit, timer, object-break, reward, and composed action transition in `packages/core/src/remix-mining-transitions.ts` is an independent implementation derived from the pinned Remix paths `Scripts/main.js`, `Scripts/Define/functions.js`, and `Scripts/mineobject.js`. Ten hit and four update-frame browser observations are stored under `miningHitSemantics` in the reference corpus and compared by Vitest and Playwright. No upstream source code or artwork was copied. The source repository's MIT notice and inherited-material rights caveat apply to derived behavior and data.

## Mine object catalog

`packages/content/src/remix-mine-content.json` is derived from the pinned Remix runtime capture: 72 base object definitions, 78 special anchors, `SKIN_LAYER_AMOUNTS`, and the 498-word `DICTIONARY_ENGLISH` table. Its embedded source metadata records commit `0e0f4bf5a9c66e5603cda2ce4bd54213023dae21`, source files, and the upstream MIT notice. `pnpm content:sync` reconstructs the tracked data file from the oracle fixture. This is a deliberate content port for compatibility; no upstream game code or artwork was copied.

## Story milestone extraction

`storySemantics` in the reference corpus retains the nine chapter names, 61 milestone keys/order/conditions/objectives/page assignments, the source text of function-valued objective expressions, and captured outputs at controlled mine levels/formats. `packages/content/src/remix-story-milestones.json` is generated from that fixture and carries typed objective templates plus the same source revision, file paths, and MIT notice. The typed condition evaluator, objective renderer, and pure state transitions in `packages/core/src/remix-story.ts` are independently implemented from those extracted rules; source expressions and captured text remain available for audit. The upstream MIT notice and caveat about rights to inherited Idle Mine material still apply.

`tests/fixtures/parity/remix-story-markup.json` preserves the complete pinned Story `<article>` template and a source-ordered descriptor for its 62 conditional blocks, including narrative text, Vue directives, object-preview attributes, and referenced image paths. `scripts/extract-story-markup.mjs` reads the clean, SHA-pinned upstream `index.html` without modifying it; `pnpm test:reference` verifies that the fixture still matches. This full source-derived template is a compatibility fixture only and has not been copied into product source or assets. Preserve the Remix MIT notice when deriving implementation data; the inherited Idle Mine rights caveat remains unresolved.

`apps/web/src/lib/MineObjectCanvas.svelte` independently implements the pinned mine-object compositing sequence. It uses the unmodified `Images/stone_new.png` atlas described in the ledger and carries the repository's full MIT notice beside the asset. This is the first copied upstream art asset in the product tree; inherited-game rights are not established by that repository notice alone.

The `payUSDebtSemantics` corpus field captures the `payUSDebt()` branch effects and button amount from `Scripts/Define/functions.js` and `index.html`. `packages/core/src/remix-story-interactions.ts` re-expresses those alert/log outcomes and the non-spending behavior; it does not copy the source function. Four controlled Money values are compared in Vitest and Chromium. The upstream MIT notice and inherited-material rights caveat apply to this derived behavior and text.

The `storyTabSemantics` corpus field captures four `changeTab()` state/timer cases from `Scripts/Define/functions.js`. `packages/core/src/remix-story-tabs.ts` independently represents the tab transition and delayed platform effects; no source code is copied. The fixture records observable state and timer outcomes, including the default number-format selection index returned by the reference.

`offlineProgressionSemantics` captures ten isolated calls through Remix `functions.loadGame()` with controlled rate functions, clock reads, localStorage, and message logging. `packages/core/src/remix-offline-progression.ts` independently implements the offline threshold, cap, reward arithmetic, message construction, resource maxima, and save effect from `Scripts/Define/functions.js`, `Scripts/Define/game.js`, and `Scripts/upgrade.js`. No upstream source code is copied; upstream MIT and inherited-material rights caveats apply to the derived behavior and captured strings.

`saveSemantics` captures the current save schema fields, serialization shape, encoding order, absent/empty group behavior, Base64 variants, malformed-input branches, and ASCII/Unicode codec vectors from `Scripts/Define/functions.js`, `Scripts/Define/game.js`, and `index.html`. It contains normalized keys, scalar values, lengths, and synthetic JSON; no real player save or upstream source code was copied. `packages/persistence/src/remix-save-codec.ts` independently reimplements the wrapper; Vitest and Chromium compare it with the source vectors. It does not copy an upstream codec function or apply imported game state. The upstream MIT and inherited-material rights caveats apply to this derived behavior and fixture.

## Mining formula implementation

`packages/core/src/mining-rates.ts` independently expresses the pinned active/idle damage and resource-rate equations. `packages/core/src/remix-mining-upgrades.ts` independently evaluates the mining-related effect subset from upgrade levels and injected Power values.
