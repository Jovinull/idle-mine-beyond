# Project status

Last updated: 2026-09-29

## Phase

**Phase 0 — Foundation / Reference Archaeology.** Source-backed Decimal, RNG, formatter, mine-object, mining-rate, mining-upgrade-factor, upgrade formula/purchase, mining hit/reward, offline-load, save-codec, Story state, and pickaxe craft-transaction slices are implemented and tested. A standalone source-template Story renderer and mine-object Canvas adapter are compared with captured runtime and pixel fixtures. The game shell, simulation loop, persistence integration, and final UI have not been implemented.

## Compatibility target

Idle Mine: Remix, repository default branch main, commit **0e0f4bf5a9c66e5603cda2ce4bd54213023dae21**. Remux is pinned separately as prior art only. See the [source manifest](sources/reference-manifest.json).
