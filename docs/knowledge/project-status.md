## Phase

**Phase 1 — Deterministic core (in progress).** The Phase 0 reference foundation is pinned and documented. Source-backed Decimal, RNG, formatter, mine-object, mining-rate, mining-upgrade-factor, upgrade formula/purchase, mining hit/reward, offline-load action composition with live state-derived rates, wrapped-save decoding/field application/offline orchestration, Story state, pickaxe craft-transaction, and fresh simulation-state initialization slices are implemented and tested. A browser session coordinator now selects fresh, legacy, or Beyond saves, serializes actions, and persists source save effects. The Svelte route now connects mining, random pickaxe crafting, Story, the source-backed upgrade shop, Settings, Powers/Wisdom, and the three-confirmation Hard Reset flow. Browser recovery supports acknowledged legacy-save and Beyond v1 file imports through the backup-aware coordinator. A native Tauri save adapter maps the shared primary/backup persistence port to allowlisted files under app data; native WebView save/reload validation, full save-export shape parity, and full-screen visual parity remain open.
