# Parity matrix

Status reflects evidence and validation, not code presence. Unstarted areas remain **not started**. “Foundation only” means the test harness exists but no game behavior has been implemented or certified. Every row is mapped to source functions, relevant branches, fixtures, tests, and evidence limits in the [source-to-test traceability audit](parity-traceability/README.md). A row may be proposed as Certified only after every relevant path in its map is covered and all evidence columns are satisfied. Non-exhaustive formula/RNG inputs do not block certification when their source boundaries, fixed-seed sample, and no-divergence differential meet the map rule; unresolved branches, save/platform domains, and visual state gaps remain open. The parity-v1 gate covers the web build; native packaging, native storage, and running Tauri WebView behavior are outside that gate.

**Pickaxe crafting visual evidence (2026-11-07):** the source-paired Mining
screen now includes the maximum Gem Waster cost (35) and disabled increase
control in both themes at 1440×900. Exact pixels and both source/implementation
disabled-control states are asserted in
`tests/e2e/pickaxe-crafting-visual.spec.ts`; other crafting panel states and
viewports remain open.

**Settings keyboard repeat evidence (2026-11-07):** a source-paired Chromium
E2E now sends repeated trusted ArrowLeft keydowns while the save text field is
focused. Both runtimes report `repeat=false` then `repeat=true`, prevent caret
movement, and select the same mine object; the focused comparison passed 1/1.
Keyboard layouts and IME behavior remain open.
