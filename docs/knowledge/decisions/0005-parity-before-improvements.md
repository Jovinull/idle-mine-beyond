# ADR 0005: Parity before improvements

- Status: Accepted
- Date: 2026-09-28

## Decision

No intentional player-visible deviations before parity-v1 without an accepted behavioral exception. Keep improvements in POST_PARITY_BACKLOG.md.

## Reason

Uncontrolled redesign, rebalancing, and mechanic simplification make it impossible to know whether the reimplementation matches Remix.

## Consequences

Every task affecting observable behavior cites the reference, includes parity evidence, and updates the matrix and relevant knowledge document.
