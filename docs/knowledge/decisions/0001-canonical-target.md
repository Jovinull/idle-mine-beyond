# ADR 0001: Canonical compatibility target

- Status: Accepted
- Date: 2026-09-28

## Decision

The pinned final Idle Mine: Remix source and behavior define the initial compatibility target. The original Idle Mine is historical lineage. idle-mine-remux is prior art only.

## Reason

The requested product is a compatible modern implementation of Remix, and its source/assets/runtime are available. Treating the original or Remux as canonical would replace Remix-specific behavior.

## Consequences

Research and fixtures cite the pinned Remix SHA. Conflicts are documented. The exact source hierarchy is in lineage.md.
