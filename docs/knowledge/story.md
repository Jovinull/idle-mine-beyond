# Story system

Story behavior is a compatibility target. Preserve the source order, chapter assignment, text, jokes, grouping, embedded mine-object previews, and interactions. Source oddities are not permission to edit the story.

## Verified legacy behavior

Evidence is pinned to [Idle Mine: Remix commit `0e0f4bf5a9c66e5603cda2ce4bd54213023dae21`](sources/reference-manifest.json): `Scripts/Define/game.js` defines chapters and milestones; `Scripts/Define/functions.js` evaluates conditions and controls story state; `index.html` contains the rendered story blocks and chapter controls. Controlled browser extractions are `storySemantics`, `payUSDebtSemantics`, and `storyTabSemantics` in [the reference corpus](../../tests/fixtures/parity/remix-reference-corpus.json).

- Remix has nine ordered chapter titles and 61 ordered milestones (indices 0–60). Each milestone has a condition expression, an objective that is either literal text or a function, and a page index. The probe preserves every condition, objective kind, dynamic function source/output at initial state, key, index, and page.
- The 61 distinct condition expressions are exercised at their relevant boundaries in the oracle. Beyond stores typed equivalents in [the generated milestone catalog](../../packages/content/src/remix-story-milestones.json); raw expressions remain alongside those descriptors for audit. `pnpm content:check` verifies the generated catalog against the captured source data.
- `storyUnlocked(key)` evaluates the condition directly. `storyDisplayed(key)` is true when that condition is true and the selected page equals the milestone page; it does not consult `highestUnlocked`.
- `getNextStoryText()` scans from the first milestone and returns the objective for the first currently false condition. The source has 38 function-valued objectives. Beyond stores their typed literal, mine-level, or formatted-number forms and renders them through injected number-formatting functions. The corpus captures all 38 outputs at highest mine-object levels 0, 12, 214, and 215, and captures the two formatter-sensitive objectives with all 40 notations (152 level samples and 80 notation samples).
- `getMaxStoryPage()` scans milestones from the end and returns the page of the last currently satisfied condition. Its source fallback is page 3, but the initial `gameStart: true` condition makes the captured fresh-game maximum page 0.
- Page increase is `Math.min(page + 1, maxPage)`; page decrease is `Math.max(page - 1, 0)`. Increasing from a saved page beyond the current maximum snaps to that maximum.
- On each main-loop frame, `Scripts/main.js` calls `refreshStoryNotifications()` after its save check. The refresh scans every remaining index from `highestUnlocked + 1` through the end; it does not stop at an unsatisfied condition. Every true condition advances `highestUnlocked` to that index and increments `notifications` once.
- The high-water behavior can skip later notifications for a milestone that becomes true at an earlier index after the high-water mark has passed it. A two-stage captured source sequence first unlocks `planetcoin` and advances the mark to 28 while `firstMud` is false; then `firstMud` becomes true and visible, but notification progress remains at 28 with the same count. Reproduce this behavior during parity.
- The `fiftyTrillion` block's `PAY` button calls `payUSDebt()`. With Money below `22e12`, Remix shows “You can't afford to pay off the debt right now.” At the exact threshold or above, it shows “You really tried. But then you noticed that it's just a game.” and logs `ERROR: Exception occurred while paying off US National debt: game money couldn't be converted to USD` in error color `#ff0900`. It never subtracts Money. Four controlled balances capture below, exact, above, and `1e300`; the label uses `formatThousands(22e12, 1e100)`.
- `changeTab()` stores `story.scrollY` from the story scroller's current `scrollTop` whenever the current tab is Story. Selecting Story clears notifications and schedules scroll restoration after 30 ms, including when Story is selected again while already active. Selecting Settings schedules the number-format select refresh after 50 ms. Four controlled oracle cases cover leaving Story for Settings, entering Story, selecting Story again, and leaving another tab. They verify source state and timer effects; the Beyond screen has not wired these effects to real controls.
- In the captured fresh state, the delayed Settings refresh sets the number-format select's `selectedIndex` to `-1`. The source creates the default formatter separately from the formatter list and searches by object identity; this is recorded in [legacy quirks](legacy-quirks.md). The mounted settings control's visual presentation is not yet captured.
- The story markup includes two separate blocks guarded by `storyDisplayed('mineUniverse')`; both are in source order on the final page. Preserve both blocks and their order. Other blocks embed fixed mine-object previews and the `PAY` control. The exact `<article>` template and descriptors for all 62 ordered `storyDisplayed` blocks are now captured in [the story markup fixture](../../tests/fixtures/parity/remix-story-markup.json); it contains 61 distinct keys because `mineUniverse` is intentionally rendered twice.
- `scripts/extract-story-markup.mjs` extracts only from the clean pinned `index.html`, verifies its commit against the source manifest, and refuses a dirty or mismatched reference checkout. `pnpm reference:story-markup` compares the fixture with that source; `pnpm reference:story-markup:capture` is an explicit reviewed recapture. This is source-template evidence, not a runtime DOM or visual comparison.
- `scripts/extract-story-runtime.mjs` serves the clean pinned checkout read-only, substitutes the hash-verified CDN snapshots, fixes the clock and seeded `Math.random`, and suppresses the animation loop. Playwright Chromium captured the fresh Story page and all nine pages with every source milestone condition asserted unlocked. The fixture records page headings, objective output, each rendered root block's text/HTML, mine-object canvas dimensions, and computed Story styles. The controlled state sets the highest mine level to 215, highest Money to `5e13`, maximum Planet Coins to 1, and one level in each of Blacksmith, Gem Waster, and the first Wisdom upgrade; this is an oracle probe, not a Beyond save fixture. `pnpm reference:story-runtime` replays and compares the pinned runtime; `pnpm reference:story-runtime:capture` is an explicit reviewed recapture. Exploratory screenshots for all-unlocked pages 1 and 9 are written to ignored `.research/outputs/story-runtime/`; they are not approved Beyond baselines.
- The runtime snapshot is pinned to Chromium `154.0.8037.58`, Playwright `1.63.0`, light color scheme, and 1440×900. It records computed CSS and rendered markup, but does not compare a Beyond Story UI, capture every theme/viewport, certify input behavior, or test real game-state integration.
- Across the nine fully unlocked pages, the source renders 48 preview occurrences covering 47 unique mine-object levels. The pinned runtime probe captures each 256×224 canvas as raw RGBA; compressed source baselines and hashes are tracked under [`tests/fixtures/visual/remix-story-mine-objects`](../../tests/fixtures/visual/remix-story-mine-objects/README.md). `pnpm reference:story-pixels` replays the clean reference and verifies them; `pnpm reference:story-pixels:capture` is a reviewed recapture command.

## Beyond implementation

`packages/core/src/remix-story.ts` implements the typed condition evaluator, source-ordered notification transition, maximum-page lookup, direct-condition visibility selector, next locked milestone selector, objective text renderer, and page navigation clamps. `remix-story-interactions.ts` returns the exact alert/error-log effects for the debt joke without mutating Money and builds its button label with injected formatting. `remix-story-tabs.ts` models the tab state transition and emits delayed scroll-restore or number-format-select effects. Objective and button formatting are injected so the core remains independent of the formatter package and UI. These are pure core slices: they receive state and definitions and have no UI, save, timer, or browser dependency.

Vitest compares every condition boundary, six controlled state transitions, the two-stage high-water sequence, dynamic objective strings, all 40 formatter outputs, four debt-interaction balances, and four tab/scroll scenarios with the pinned corpus. Playwright Chromium performs the same comparisons in a browser harness. `apps/web/src/lib/MineObjectCanvas.svelte` is a source-derived renderer adapter for Story mine-object previews; a dedicated Playwright test compares its 48 rendered occurrences with the raw pinned-source RGBA baselines. Thirty-six occurrences have identical pixel hashes. For the other twelve, alpha is exact and every RGB channel differs by at most one value in no more than 2% of pixels. The cause of these small Canvas compositor/raster differences is not established. This measured test tolerance is not an accepted behavioral exception. The component does not render narrative blocks or wire the source `damage()` action to live game state. This does not certify full Story UI, app-level alert/log integration, live DOM scroll restoration, or persistence.
